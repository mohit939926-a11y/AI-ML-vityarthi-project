# Project Statement

**Project title:** Loan Approval Predictor
**Course:** Fundamentals in AIML (VITyarthi - Build Your Own Project)
**Student:** Mohit Thakur | **Reg. No.:** 25MIM10126

## Problem Statement
Banks receive a large number of loan applications, and checking each one manually is slow and can be inconsistent. This project builds a machine learning model that predicts whether a loan application is likely to be **approved or rejected**, using applicant details such as income, credit history, education, loan amount and property area.

## Objectives
1. Prepare and clean a loan application dataset.
2. Train and compare three classification models (Logistic Regression, Decision Tree, Random Forest).
3. Select the best model using accuracy, precision, recall and F1-score.
4. Provide a simple Streamlit web interface that shows the prediction and approval probability.

## Scope
- Binary classification (Approved / Rejected) on 11 applicant features.
- Educational project using a synthetic dataset with the layout of the Kaggle Loan Prediction dataset.
- Not intended for real banking decisions.

## Expected Outcome
A working web application backed by a trained ML model, with documentation, test cases and a project report.
